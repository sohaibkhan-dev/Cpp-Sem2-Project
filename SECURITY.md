## Reporting a Vulnerability

If you discover a security vulnerability in this project, please help us keep it safe by following these steps:

1. **Do not open a public issue**.  
2. Instead, email me at **sohaibkundi2@gmail.com** with details of the vulnerability.  
3. Please include:
   - A clear description of the vulnerability.  
   - Steps to reproduce the issue (if possible).  
   - Any suggested fix or patch.  

---

## Response Process

- I will acknowledge your report within **7 days**.  
- If the vulnerability is confirmed, I will work on a fix and release a patched version as soon as possible.  
- Please do not publicly disclose the vulnerability until it has been resolved.  

Thank you for helping keep this project secure!
